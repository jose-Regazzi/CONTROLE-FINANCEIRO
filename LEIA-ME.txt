CONTROLE FINANCEIRO — APP INSTALÁVEL (PC E CELULAR)
=====================================================

É um PWA (Progressive Web App): o mesmo app roda no PC (Chrome/Edge) e no celular
(Android/iPhone), abre em janela própria, tem ícone e funciona offline.
Os dados ficam SALVOS NO APARELHO (não vão para servidor nenhum).

1) PUBLICAR A PASTA "APP" (uma vez só) — escolha uma opção:
   • Netlify Drop (mais fácil): acesse https://app.netlify.com/drop e arraste a pasta APP.
     Ele gera um link https://xxxx.netlify.app
   • GitHub Pages: suba o conteúdo da pasta APP num repositório e ative Pages.
   A pasta APP NÃO contém seus dados financeiros — é só o aplicativo.

2) INSTALAR
   • PC (Chrome/Edge): abra o link › ícone "Instalar" na barra de endereço
     (ou ☰ Dados › Instalar agora).
   • Android (Chrome): abra o link › menu ⋮ › "Instalar app".
   • iPhone (Safari): abra o link › Compartilhar › "Adicionar à Tela de Início".

3) CARREGAR OS DADOS
   • Na 1ª abertura: "Carregar backup (.json)" e escolha
     controle_financeiro_backup_2026-11-20.json (já gerado com a planilha atual),
     ou "Importar planilha (.xlsx)".

4) LEVAR DADOS DE UM APARELHO PARA OUTRO
   • No aparelho de origem: ☰ Dados › Exportar backup (ou Compartilhar → WhatsApp/Drive).
   • No aparelho de destino: ☰ Dados › Carregar backup.
   Obs.: os aparelhos NÃO sincronizam sozinhos — o backup é o meio de transferência.

ARQUIVOS
   CONTROLE_FINANCEIRO_DASHBOARD.html  → versão local, abre direto com 2 cliques (dados embutidos)
   APP\                                → versão instalável (publicar conforme item 1)
   controle_financeiro_backup_*.json   → seus dados para carregar no app


NOVIDADES (20/11/2026)
   • Dados próprios do app: não depende mais da planilha (conversão automática na 1ª abertura).
   • Versões: ☰ Dados › Versões anteriores (cópia diária no aparelho e na nuvem, 60 dias).
     Requer rodar de novo o SUPABASE_SETUP.sql no SQL Editor do Supabase (cria a tabela cf_history).
   • Fechar mês: botão no card Resultado — trava o mês e o seguinte parte do saldo realizado.
   • Previsões: lançamentos estimados aparecem como PREVISÃO e são baixados ao lançar/importar a compra real.
   • Importar fatura do banco: na fatura do cartão › "Importar do banco" (CSV, OFX ou Excel).
